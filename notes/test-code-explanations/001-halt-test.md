## 001-halt-test.c の解説

`001-halt-test.c` は、小さな自作VMの `HALT` 命令を確認するテストです。

`HALT` はVMの実行を停止する命令です。このテストでは、メモリの先頭に `HALT` 命令を1つだけ置き、それを読み取って `running` を `false` にできるかを確認しています。

メモリに置いている命令は次の4バイトです。

```text
01 00 00 00
```

32bit命令として見ると、これは `0x01000000` になります。

## VMの状態

冒頭で、HALTテストに必要な最小限の状態を用意しています。

```c
uint8_t memory[1024 * 1024] = {0};
uint32_t pc = 0x00000000;
bool running = true;
```

意味は次の通りです。

- `memory`: 1MBのメモリ。1要素が `uint8_t` なので1バイト単位
- `pc`: プログラムカウンタ。次に読む命令のアドレス
- `running`: VMの実行継続フラグ

`running` が `true` の間、VMは命令を読み続けます。`HALT` を実行すると `running = false` になり、ループが終了します。

## メモリに置かれる命令

次の部分で、メモリの先頭に `HALT` 命令を直接書き込んでいます。

```c
memory[0x00000000] = 0x01;
memory[0x00000001] = 0x00;
memory[0x00000002] = 0x00;
memory[0x00000003] = 0x00;
```

メモリ配置としては次の通りです。

```text
0x00000000: 01 00 00 00    HALT
```

このVMでは1命令を4バイト固定長として扱うので、この4バイトが1つの命令です。

## 実行ループ

命令の実行は、次の `while` ループで行われます。

```c
while (running) {
    ...
}
```

最初は、

```c
bool running = true;
```

なので、ループに入ります。

`HALT` 命令が実行されると、

```c
running = false;
```

になり、次のループ判定で終了します。

## 命令の読み取り

ループの中では、`pc` が指す場所から4バイトを読み、1つの32bit命令に組み立てています。

```c
uint32_t inst =
    ((uint32_t)memory[pc] << 24) |
    ((uint32_t)memory[pc + 1] << 16) |
    ((uint32_t)memory[pc + 2] << 8) |
    ((uint32_t)memory[pc + 3]);
```

`pc` は最初 `0x00000000` なので、実際には次の4バイトを読んでいます。

```text
memory[0] = 0x01
memory[1] = 0x00
memory[2] = 0x00
memory[3] = 0x00
```

このVMでは、先頭のバイトを32bit値の一番上に置くビッグエンディアンの形で命令を組み立てています。

```text
memory[pc]     << 24  -> 0x01000000
memory[pc + 1] << 16  -> 0x00000000
memory[pc + 2] << 8   -> 0x00000000
memory[pc + 3]        -> 0x00000000
```

これらを `|` で合成すると、次の値になります。

```text
inst = 0x01000000
```

## PCを進める

命令を1つ読んだ後、`pc` を4進めています。

```c
pc += 4;
```

このVMでは1命令が4バイトなので、次の命令は4バイト後にあります。

今回の初期値は `0x00000000` なので、fetch 後は次の値になります。

```text
pc = 0x00000004
```

ただし、このテストでは `HALT` で停止するので、次の命令を読むことはありません。

## opcode の取り出し

読み取った32bit命令から、上位8bitを `opcode` として取り出しています。

```c
uint8_t opcode = (inst >> 24) & 0xff;
```

`inst` は `0x01000000` です。

右に24bitシフトすると、一番上の1バイトだけが下位に来ます。

```text
0x01000000 >> 24 = 0x01
```

したがって、

```text
opcode = 0x01
```

になります。

この `0x01` が `HALT` を表しています。

## HALT の実行

decode した `opcode` が `0x01` なら、VMを停止します。

```c
if (opcode == 0x01) {
    running = false;
    printf("CPU halted.\n");
}
```

今回の命令は `0x01000000` なので、`opcode` は `0x01` です。

したがって、この分岐に入り、次の処理が行われます。

```c
running = false;
```

これによって `while (running)` が終了します。

同時に、

```c
printf("CPU halted.\n");
```

によって停止したことを表示します。

## 実行結果

期待される出力は次の通りです。

```text
CPU halted.
```

実行の流れを整理すると、次のようになります。

```text
1. pc = 0x00000000 から4バイト読む
2. 01 00 00 00 を 0x01000000 として組み立てる
3. 上位8bitから opcode = 0x01 を取り出す
4. opcode == 0x01 なので HALT と判定する
5. running = false にして実行ループを止める
```

要するにこのコードは、`HALT` 命令を読み取り、VMの実行ループを止められるかを確認する最小テストです。
