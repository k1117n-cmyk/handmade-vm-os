## Day 9: STB

```text
名前: STB
分類: memory-register instruction
目的: レジスタの下位8bitをmemoryへ書く
命令長: 4 byte
bit配置:
  bits 31..28: type = 3
  bits 27..24: op = 1
  bits 23..20: rd = address register
  bits 19..16: rs = source register
  bits 15..0 : unused = 0
読むレジスタ: rd, rs
書くレジスタ: なし
読むメモリ: なし
書くメモリ: memory[regs[rd]]
PCの変化: fetch時に +4
条件フラグの変化: なし
エラー時: register number が範囲外、または address が memory 範囲外なら停止
手作りテスト:
成功条件:
```

```test
memory[0x20] = 0x41
LDB後 R2 = 0x41
```

テストプログラム:

```text
MOVI R1, 0x20   -> 0x40100020 -> 40 10 00 20
MOVI R0, 65     -> 0x40000041 -> 40 00 00 41
STB [R1], R0    -> 0x31100000 -> 31 10 00 00
LDB R2, [R1]    -> 0x30210000 -> 30 21 00 00
```

重要なのはここです。

```asm
STB [R1], R0
```

では、アセンブリ上の意味は:

```text
R1の中身をアドレスとして使う
R0の下位8bitを memory[そのアドレス] に書く
```

Cで書くなら:

```c
memory[regs[rd]] = regs[rs] & 0xff;
```

今回の値を入れると:

```c
memory[regs[1]] = regs[0] & 0xff;
memory[0x20] = 0x41;
```

```text
0x 3 1 1 0 0000
   | | | |   |
   | | | |   +-- unused = 0
   | | | +------ rs = 0
   | | +-------- rd = 1
   | +---------- op = 1
   +------------ type = 3
```
