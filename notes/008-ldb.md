## Day 8: LDB

名前: LDB
分類: memory-register instruction
目的: VM内メモリから1 byteを読み、レジスタへ入れる
命令長: 4 byte
bit配置:
  bits 31..28: type = 3
  bits 27..24: op = 0
  bits 23..20: rd
  bits 19..16: rs
  bits 15..0 : unused = 0
読むレジスタ: rs
書くレジスタ: rd
読むメモリ: memory[regs[rs]] から1 byte
書くメモリ: なし
PCの変化: fetch時に +4
条件フラグの変化: なし
エラー時: register number が範囲外、または address が memory 範囲外なら停止
手作りテスト: LDB R0, [R1] -> 0x30010000
成功条件: R1 = 0x10, memory[0x10] = 0x41 のとき、実行後 R0 = 0x41

テストプログラム:

```text
MOVI R1, 0x10
LDB R0, [R1]
SYSCALL 0
HALT
```

メモリ配置:

```text
0x00000000: 40 10 00 10    MOVI R1, 0x10
0x00000004: 30 01 00 00    LDB R0, [R1]
0x00000008: 60 00 00 00    SYSCALL 0
0x0000000C: 01 00 00 00    HALT

0x00000010: 41             'A'
```

期待する出力:

```text
A
CPU halted.
```

手計算:

```text
LDB R0, [R1]

type = 3
op   = 0
rd   = 0
rs   = 1

0x30010000

memory[0] = 0x30  // type=3, op=0
memory[1] = 0x01  // rd=0, rs=1
memory[2] = 0x00
memory[3] = 0x00
```

実行の流れ:

```text
1. MOVI R1, 0x10
   R1 = 0x10

2. LDB R0, [R1]
   address = R1
   address = 0x10
   memory[0x10] = 0x41
   R0 = 0x41

3. SYSCALL 0
   R0の下位8bitを文字として出す
   0x41 = 'A'

4. HALT
   CPU halted.
```

今回の大事な違い:

```text
MOVIは、命令の中に入っている数字をレジスタへ入れる。
LDBは、レジスタが指すmemoryの場所から1 byteを読む。
```

つまり:

```text
MOVI R1, 0x10
```

は「R1に0x10を入れる」。

```text
LDB R0, [R1]
```

は「R1の中身をアドレスとして使い、そのmemoryから1 byte読んでR0へ入れる」。

Cコードでの中心:

```c
uint32_t address = regs[rs];
regs[rd] = memory[address];
```

ただし実際には、`rd` と `rs` が `R0`-`R7` の範囲か、`address` がmemory範囲内かを確認してから読む。
