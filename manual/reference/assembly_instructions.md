# アセンブリ言語における命令（アドレッシングモード）の分類

アセンブリ言語では、処理対象となるデータ（オペランド）の場所をどのように指定するか（アドレッシングモード）によって、命令が大きく以下の5つに分類されます。


# アセンブリ言語における命令分類（システム・制御・メモリ系統）

アドレッシングモード（データの場所）による5つの分類に加え、CPUの制御、プログラムの流れの変更、外部メモリとのやり取りを行うために、以下の重要な命令分類が存在します。

---

##  追加の命令分類一覧表

| 分類名（英語 / 日本語） | 役割と特徴 | 具体例 |
| :--- | :--- | :--- |
| System instruction（システム制御命令） | CPUの状態変更、割り込み制御、システム全体の制御や停止を行う。 | `HALT`（停止）, `NOP`（何もしない） |
| Control flow instruction（制御流命令 / 分岐命令）| PC（プログラムカウンタ）を書き換えて、プログラムの実行順序（流れ）を変える。 | `JUMP`（無条件分岐）, `CALL`（関数呼出） |
| Memory access instruction（メモリアクセス命令） | CPUのレジスタと外部メモリ（RAM）の間で、データの読み書きを行う。 | `LOAD`（メモリから読込）, `STORE`（メモリへ書込） |

---

##  各命令の詳細と設計イメージ

### ① System instruction（システム制御命令）
   概要: 計算ではなく、CPUや仮想マシン（VM）の動作そのものをコントロールします。
   イメージ: 「処理をすべてストップしてVMを終了しろ」
   コード例: `HALT`

### ② Control flow instruction（制御流命令 / 分岐命令）
   概要: 通常は上から下に実行されるプログラムの流れを、ループ（for/while）や条件分岐（if文）のために別の場所へジャンプさせます。
   イメージ: 「指定したアドレスへ強制的にジャンプしろ」「関数を実行して、終わったら戻ってこい」
   コード例: `JUMP 0x1000`、`CALL 0x2004`

### ③ Memory access instruction（メモリアクセス命令）
   概要: RISC型アーキテクチャなどで特に重視される分類で、演算器（ALU）に通す前のデータをメモリから持ってきたり、計算結果をメモリに保存したりします。
   イメージ: 「メモリのA番地からデータをレジスタにロードしろ」「レジスタの値をメモリのB番地にストアしろ」
   コード例: `LOAD R1, [0x5000]`、`STORE [0x5000], R1`


##  命令分類の一覧表

| 分類名（日本語 / 英語） | データの場所 | 特徴 |
| :--- | :--- | :--- |
| ① 即値命令(Immediate) | 命令の中（定数） | メモリやレジスタを参照しないため最速。 |
| ② レジスタ命令(Register) | CPUのレジスタ内 | CPU内部の回路だけで完結するため高速。 |
| ③ 直接（絶対）命令(Direct / Absolute) | 指定したメモリ番地 | メモリの特定の住所（固定アドレス）を直接指定する。 |
| ④ 間接命令(Indirect) | メモリの住所が書かれた場所 | レジスタ等が指す「さらに先の住所」のメモリを見に行く。 |
| ⑤ 相対命令(Relative) | 現在の位置からの差分 | 「ここから5行先へジャンプ」など、主に条件分岐で使用。 |


##  各命令の詳細とコード例

### ① 即値命令 (Immediate instruction)
   概要: 処理する値そのものが命令コードの中に埋め込まれています。
   イメージ: 「レジスタに 数字の 5 を足せ」
   コード例: `ADD R1, #5` （`#5` がデータそのもの）

### ② レジスタ命令 (Register instruction)
   概要: CPUの内部にある記憶場所（レジスタ）同士でデータを処理します。
   イメージ: 「レジスタ1に レジスタ2の中身 を足せ」
   コード例: `ADD R1, R2`

### ③ 直接命令 (Direct instruction)
   概要: メモリの特定の絶対アドレスを直接指定してデータを読み書きします。
   イメージ: 「メモリ1000番地 にあるデータをレジスタ1にコピーしろ」
   コード例: `MOV R1, [1000]`

### ④ 間接命令 (Indirect instruction)
   概要: レジスタやメモリに「データの置いてある住所（ポインタ）」を格納しておき、それを経由してデータにアクセスします。配列の処理などに必須です。
   イメージ: 「レジスタ2に書いてある住所のメモリを見に行き、その中身をレジスタ1に入れろ」
   コード例: `MOV R1, [R2]`

### ⑤ 相対命令 (Relative instruction)
   概要: 現在実行している命令の位置（プログラムカウンタ）を基準に、どれだけ離れた場所に移動するかを指定します。
   イメージ: 「もし条件が合えば、今の場所から10行後ろにジャンプしろ」
   コード例: `BNE +10`
