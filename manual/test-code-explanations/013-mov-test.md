## 013-mov-test.c の解説

`013-mov-test.c` は、小さな自作VM上で `MOV`、つまり「あるレジスタの32bit値を別のレジスタへコピーする命令」が正しく動くかを確認するテストです。

全体としては、次の命令列をメモリに直接書き込んで実行します。

```asm
MOVI R0, 0x12345
MOV R2, R0
HALT
```

期待する結果は次の通りです。

```text
R0 = 0x00012345
R2 = 0x00012345
```

`MOV` は、元のレジスタを空にする命令ではありません。`R0` の値を残したまま、同じ値を `R2` へコピーします。

## VMの状態

冒頭でVMの状態を用意しています。

```c
uint8_t memory[1024 * 1024] = {0};
uint32_t pc = 0x00000000;
uint32_t regs[8] = {0};
bool running = true;
```

意味は次の通りです。

- `memory`: 1MBのメモリ。1要素が `uint8_t` なので1バイト単位
- `pc`: プログラムカウンタ。次に読む命令のアドレス
- `regs`: 32bitレジスタ8本、`R0` から `R7`
- `running`: VMの実行継続フラグ

## メモリに置かれるプログラム

このテストでは、VMが実行する命令を `memory` に直接書き込んでいます。

```text
0x00000000: 40 01 23 45    MOVI R0, 0x12345
0x00000004: 10 20 00 00    MOV R2, R0
0x00000008: 01 00 00 00    HALT
```

命令は4バイト固定長なので、`pc` は `0x00`, `0x04`, `0x08` と進みます。

## 命令の読み取り

VMは1命令を4バイト固定長として読んでいます。

```c
uint32_t inst =
    ((uint32_t)memory[pc] << 24) |
    ((uint32_t)memory[pc + 1] << 16) |
    ((uint32_t)memory[pc + 2] << 8) |
    ((uint32_t)memory[pc + 3]);

pc += 4;
```

メモリ上の4バイトをビッグエンディアンとして `uint32_t` に合成しています。

## 命令フォーマット

命令は次のように分解されます。

```c
uint8_t type = (inst >> 28) & 0x0F;
uint8_t op = (inst >> 24) & 0x0F;
uint8_t rd = (inst >> 20) & 0x0F;
uint8_t rs = (inst >> 16) & 0x0F;
uint32_t imm = inst & 0x000FFFFF;
```

`MOV` では `rd` と `rs` を使います。`imm` は使いません。

```text
[ type:4 ][ op:4 ][ rd:4 ][ rs:4 ][ unused:16 ]
```

## MOVI

最初に `MOVI R0, 0x12345` で、コピー元になる値を `R0` に入れます。

```c
regs[rd] = imm;
```

この命令のあと、`R0` は `0x00012345` になります。

## MOV

このテストで一番重要なのはここです。

```c
} else if (type == 1 && op == 0) {
    ...
    regs[rd] = regs[rs];
}
```

`MOV R2, R0` の命令は `0x10200000` です。

分解すると次のようになります。

```text
type = 1
op   = 0
rd   = 2
rs   = 0
```

このVMでは `MOV` の `rd` を「コピー先レジスタ」、`rs` を「コピー元レジスタ」として使っています。

したがって、実行内容は次の通りです。

```c
regs[2] = regs[0];
```

この時点で `regs[0]` は `0x00012345` なので、`regs[2]` も同じ値になります。

## エラーチェック

`MOV` では、実行前に `rd` と `rs` が正しいレジスタ番号か確認しています。

```c
if (rd >= 8 || rs >= 8) {
    printf("invalid register: rd=R%u rs=R%u\n", rd, rs);
    running = false;
}
```

確認しているのは、`rd` と `rs` が `R0` から `R7` の範囲に収まっているかです。

## HALT

```c
if (inst == 0x01000000) {
    running = false;
}
```

命令が `0x01000000` なら実行ループを終了します。

## 最後の判定

実行後に `R0` と `R2` を表示し、次の条件を確認します。

```c
if (regs[0] == 0x00012345 && regs[2] == 0x00012345) {
    printf("MOV test passed.\n");
    return 0;
}
```

確認しているのは、`MOV R2, R0` によって `R0` の値が `R2` にコピーされ、コピー元の `R0` もそのまま残っているかどうかです。

要するにこのコードは、レジスタからレジスタへの32bitコピーを確認する、`MOV` 命令の最小テストです。

## 実行結果

R0=0x00012345
R2=0x00012345
MOV test passed.
