## 012-inc-dec-test.c の解説

`012-inc-dec-test.c` は、小さな自作VM上で `INC` と `DEC` が正しく動くかを確認するテストです。

`INC` は指定したレジスタの値を1増やします。`DEC` は指定したレジスタの値を1減らします。

全体としては、次の命令列をメモリに直接書き込んで実行します。

```asm
MOVI R0, 0x10
MOVI R1, 0x10
INC R0
DEC R1
HALT
```

期待する結果は次の通りです。

```text
R0 = 0x00000011
R1 = 0x0000000F
```

## VMの状態

冒頭でVMの状態を用意しています。

```c
uint8_t memory[1024 * 1024] = {0};
uint32_t pc = 0x00000000;
uint32_t regs[8] = {0};
bool running = true;
```

意味は次の通りです。

- `memory`: 1MBのメモリ。1要素が `uint8_t` なので1バイト単位
- `pc`: プログラムカウンタ。次に読む命令のアドレス
- `regs`: 32bitレジスタ8本、`R0` から `R7`
- `running`: VMの実行継続フラグ

## メモリに置かれるプログラム

このテストでは、VMが実行する命令を `memory` に直接書き込んでいます。

```text
0x00000000: 40 00 00 10    MOVI R0, 0x10
0x00000004: 40 10 00 10    MOVI R1, 0x10
0x00000008: 20 00 00 00    INC R0
0x0000000C: 21 10 00 00    DEC R1
0x00000010: 01 00 00 00    HALT
```

命令は4バイト固定長なので、`pc` は `0x00`, `0x04`, `0x08`, `0x0C`, `0x10` と進みます。

## 命令の読み取り

VMは1命令を4バイト固定長として読んでいます。

```c
uint32_t inst =
    ((uint32_t)memory[pc] << 24) |
    ((uint32_t)memory[pc + 1] << 16) |
    ((uint32_t)memory[pc + 2] << 8) |
    ((uint32_t)memory[pc + 3]);

pc += 4;
```

メモリ上の4バイトをビッグエンディアンとして `uint32_t` に合成しています。

## 命令フォーマット

命令は次のように分解されます。

```c
uint8_t type = (inst >> 28) & 0x0F;
uint8_t op = (inst >> 24) & 0x0F;
uint8_t rd = (inst >> 20) & 0x0F;
uint32_t imm = inst & 0x000FFFFF;
```

`INC` と `DEC` では `rd` だけを使います。`imm` は使いません。

```text
[ type:4 ][ op:4 ][ rd:4 ][ unused:20 ]
```

## INC

`INC R0` の命令は `0x20000000` です。

分解すると次のようになります。

```text
type = 2
op   = 0
rd   = 0
```

このVMでは `INC` の `rd` を「値を増やす対象のレジスタ」として使っています。

```c
regs[rd] += 1;
```

今回の値を入れると:

```c
regs[0] += 1;
```

`R0` は直前の `MOVI R0, 0x10` で `0x10` になっているので、`INC` 後は `0x11` になります。

## DEC

`DEC R1` の命令は `0x21100000` です。

分解すると次のようになります。

```text
type = 2
op   = 1
rd   = 1
```

このVMでは `DEC` の `rd` を「値を減らす対象のレジスタ」として使っています。

```c
regs[rd] -= 1;
```

今回の値を入れると:

```c
regs[1] -= 1;
```

`R1` は直前の `MOVI R1, 0x10` で `0x10` になっているので、`DEC` 後は `0x0F` になります。

## エラーチェック

`INC` と `DEC` では、実行前に `rd` が正しいレジスタ番号か確認しています。

```c
if (rd >= 8) {
    printf("invalid register: R%u\n", rd);
    running = false;
}
```

確認しているのは、`rd` が `R0` から `R7` の範囲に収まっているかです。

## HALT

```c
if (inst == 0x01000000) {
    running = false;
}
```

命令が `0x01000000` なら実行ループを終了します。

## 最後の判定

実行後に `R0` と `R1` を表示し、次の条件を確認します。

```c
if (regs[0] == 0x00000011 && regs[1] == 0x0000000F) {
    printf("INC/DEC test passed.\n");
    return 0;
}
```

確認しているのは、`INC R0` によって `R0` が `0x10` から `0x11` に増え、`DEC R1` によって `R1` が `0x10` から `0x0F` に減ったかどうかです。

要するにこのコードは、レジスタ1本を対象にした最小の増減命令を確認する、`INC` / `DEC` 命令のテストです。

## 実行結果

R0=0x00000011
R1=0x0000000F
INC/DEC test passed.
