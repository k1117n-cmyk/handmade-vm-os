# Day 39: small-asmの文字列と配置

```text
分類: ホスト側の開発補助ツール（VM命令の追加なし）
目的: 命令と文字列を同じ.asmへ書き、ラベルでSYSCALL 1へ渡す
入力: 従来の命令・ラベル、.string "..."、.align 4
出力: 先頭0のbyte列。命令は4 byte big-endian、文字列は1 byteずつ
成功条件: 下記の例がHello, VM!と改行を表示して停止する
```

## 最小例と手計算

```asm
JUMP start
message: .string "Hello, VM!\n"
.align 4
start:
MOVI R0, message
SYSCALL 1
HALT
```

JUMPは0〜3、messageは4〜15（本文11 byteと終端0の1 byte）、startは16です。この例では既に4の倍数なので詰め物は0 byteです。文字列を `Hi\n` にすると本文3 byteと終端0で、startは8へ移ります。`Hi!\n` なら本文4 byteと終端0の後に3 byteの0を補い、startは12です。

## 文字列

- `.string` は二重引用符で囲んだ文字列を1つだけ受け取る。空文字も許す。
- 生の文字はASCIIの表示可能文字（0x20〜0x7E）。日本語など非ASCII、実タブなど制御文字は拒否する。文字数とbyte数を一致させて手計算しやすくする。
- エスケープは `\n`（0x0A）、`\r`（0x0D）、`\t`（0x09）、`\\`、`\"` の5つだけ。`\0` や `\x41` は拒否する。
- 末尾へ0x00を必ず1 byte加える。文字列内の0は禁止するため、表示が途中で切れない。これは文字 `0`（0x30）とは別。
- 文字列の大文字・小文字、空白、`; # : ,` をそのまま保存する。コメント開始は引用符の外だけ。
- 従来の行バッファ256 byteの制約を維持する。LF付きの行はLFを含め255 byteまで。文字列専用の長さ上限は設けず、ラベルや構文を含む行全体の制限に従う。複数行文字列や連結は扱わない。

## 配置と参照

- 現在位置は命令数×4ではなく、それまでに出力したbyte数とする。
- `.align 4` は現在位置を次の4の倍数へ揃え、0〜3 byteの0を補う。数値の読み方は従来通り（`0x4` も可）だが値は4のみ。引数省略・他の値・ラベルは拒否する。
- 命令の先頭が4の倍数でなければエラー。自動整列はせず、ソースに `.align 4` を書く。文字列とラベルには整列を要求しない。
- ラベルはその行の指示を処理する前の現在位置。`pad: .align 4` のpadは詰め物の先頭なので、命令のラベルは `.align 4` の後へ置く。
- MOVIの第2引数に数値またはラベルを許す。前後参照、大小文字の扱いは分岐と同じ。SYSCALLの番号は数値のみ。
- ラベルをコード用・データ用には分類しない。分岐先の妥当性検査は従来通り行わない。実行が文字列や詰め物へ進まないよう、JUMPやHALTを配置する。
- 全体は最大0x100000 byte、ラベルは0〜0xFFFFF。末尾の整列は上限ちょうどまで許すが、その直後のラベルは範囲外。
- 絶対配置、任意byte、領域予約、式は今回扱わない。echoの移行は次回、固定バッファ0x500との関係を調べて判断する。

## 実装・エラー・検証

2回とも同じ規則でbyte数を進める。1回目で全ラベルを登録し、2回目で参照を解決して一時ファイルへ出力する。引用符内を保持してから命令名などを大文字へ揃える。

不正文字列・未対応エスケープ・不正配置・未整列命令・サイズ超過は入力パスと行番号付きで拒否する。構文やラベルエラーでは既存出力を保持し、新規出力も作らない。最終コピーのI/Oエラーでは部分出力が残り得る。成功時の命令数には文字列と配置指示を含めない。

Pythonから実際のツールを起動する `tools/test-small-asm-strings.py` で固定byte列、文字列長の変化、前後参照、エラー時の出力保持、1 MiB境界、VM出力を検証する。VM本体とwriterは変更しない。
