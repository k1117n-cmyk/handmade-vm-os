## Day 19: JNZ

```text
名前: JNZ
分類: control flow instruction
目的: zero_flag が false のときだけ PCを即値アドレスへ変更する
命令長: 4 byte
bit配置:
  bits 31..28: type = 6
  bits 27..24: op = 11
  bits 23..20: unused = 0
  bits 19..0 : imm = jump target address
読むレジスタ: なし
書くレジスタ: なし
読むメモリ: なし
書くメモリ: なし
PCの変化: fetch時に +4。zero_flag == false なら PC = imm
条件フラグの変化: なし
エラー時: imm が命令fetchできない範囲なら停止
手作りテスト: JNZ 0x20 -> 0x6B000020
成功条件: CMPでzero_flagがfalseになった後、JNZで0x20へ移動する
```

`JNZ` は、Day 18 の `JZ` と対になる条件分岐命令です。

```text
JZ:
  zero_flag == true のときジャンプ

JNZ:
  zero_flag == false のときジャンプ
```

`zero_flag` は Day 17 の `CMP` で更新します。

```asm
MOVI R0, 5
MOVI R1, 3
CMP R0, R1
JNZ different
```

この場合、`R0` と `R1` は違う値なので `zero_flag` が `false` になり、`JNZ` はジャンプします。

Cで書くなら:

```c
if (!vm->zero_flag) {
    vm->pc = inst.imm;
}
```

## 名前について

ブログでは、読みやすさを優先して `JNZ` と呼ぶ。

lesson 04 の教材側では、同じ immediate address を使う条件分岐命令を `JPNZI` と呼んでいる。

```text
ブログ上の名前    教材寄りの名前
JNZ               JPNZI
```

このリポジトリでは、Day 19時点では `JNZ` として説明し、命令番号は教材側に寄せて `type=6, op=11` を使う。

テストプログラム:

```text
MOVI R0, 1
MOVI R1, 2
CMP R0, R1
JNZ 0x18
MOVI R2, 99
HALT
MOVI R2, 7
HALT
```

メモリ配置:

```text
0x00000000: 40 00 00 01    MOVI R0, 1
0x00000004: 40 10 00 02    MOVI R1, 2
0x00000008: 24 01 00 00    CMP R0, R1
0x0000000C: 6B 00 00 18    JNZ 0x18
0x00000010: 40 20 00 63    MOVI R2, 99
0x00000014: 01 00 00 00    HALT
0x00000018: 40 20 00 07    MOVI R2, 7
0x0000001C: 01 00 00 00    HALT
```

成功条件:

```text
R0 = 1
R1 = 2
R2 = 7
zero_flag = false
```

もし `JNZ` が動かなければ、`MOVI R2, 99` が実行される。
