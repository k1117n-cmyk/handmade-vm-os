## 目的と成功条件

コマンド入力とは別のバッファに1行を保持する。
`set hello`、別のコマンド、`show`の順に実行してもhelloとLFを表示できること。
`set world`で全体を置換でき、短い内容や空へ置換しても古い末尾が表示されないこと。
新しいサンプル名は`programs/line-editor.asm` / `.bin`とする。

## 承認済みの操作

| 操作 | 動作 |
|---|---|
| `set text` | 本文と終端0を編集バッファへコピーし、追加表示せずCommand>へ戻る |
| `set`単独 | Text>で次の1行を読み、その内容で置換する |
| `set `のように区切りだけ | 空内容へ置換する。次の行はコマンドとして読む |
| `show` | 保持内容とLFを表示してCommand>へ戻る |
| `help` / `echo` | Day 41の動作を継承し、編集内容は変更しない |
| `quit` | 従来の終了文言を表示してHALT。保存・確認質問は行わない |

起動時の編集内容は空。空内容のshowはLFだけを表示する。
quit後に同じプログラムを再起動しても、以前の内容は復元せず空で始める。
独立したeditorを起動する方式にはせず、同じコマンドループにset / showを加える。

helpの既存案内を継承し、次の2行を追加する。行末はLFとする。

```text
set [text]: replace the stored line or read a line
show: print the stored line
```

## メモリと上限

基準は[機械状態](000-machine-state.md)の1 MiBメモリ、R0〜R7、下向きスタック。

| 領域 | 配置と用途 |
|---|---|
| 命令・定数文字列 | 0から連続配置。ファイル末尾（排他的）は0x500以下 |
| 入力バッファ | 0x500〜0x53Fの64 byte。最大63 byteと終端0 |
| 編集バッファ | 0x600〜0x63Fの64 byte。最大63 byteと終端0 |
| 戻り先スタック | 機械仕様の初期SP=0x100000から下向きに使用 |

起動時に編集バッファの先頭へ0を書く。
コピー対象は最初の終端0を含むbyte列。短い内容への置換では新しい終端0までを有効内容とし、
その後ろの旧byteを消去することは要求しない。入力バッファの再利用は編集内容に影響させない。

入力上限63 byteには、コマンド名・先頭空白・区切りも含む。
`set `は4 byteなので、同じ行の本文は最大59 byte。余分な空白があればその分だけ減る。
set単独の次の行では最大63 byteの本文を保持できる。
生成物の命令数・正確なサイズは今回固定せず、実装後に実測して記録する。
Day 41やDay 40とのバイナリ全体一致は要求しない。

## 入力と異常時の規則

[Day 41の仕様](041-command-arguments.md)のread_line / split_line / compare_commandを継承する。

- 先頭・区切りの半角空白は読み飛ばし、本文中と末尾の空白を保持する。
- タブは区切りにしない。引用符・バックスラッシュは通常の文字。大小文字を区別する。
- set単独の次の行には分割処理を呼ばず、先頭・末尾の空白も保持する。
  その行のhelp / quitも文字列として保持する。空行なら空内容にする。
- show / help / quitの非空引数はUnknown command。末尾が半角空白だけなら受理する。
- 空行、半角空白だけのコマンド、未知のコマンド、不正な引数では編集内容を変えない。
- 上限を超えた入力もLFまで消費し、保存された範囲を処理する。CRは行中でも無視し、LFで確定する。
  CRLF対応だが、CR単独では確定しない。
- 途中EOFでは既存SYSCALL 2がinput EOFを表示してVMを停止する。未完の行はコピーしない。
- NULは入力に保存し、以後もLFまで消費する。分割・コピー・表示は最初のNULまで。
- UTF-8もbyte列として扱い、入力上限で文字が途中までになる場合がある。

## コピー部品の呼び出し規約

copy_lineはR6にコピー元を受け、0x600から終端0を含めてコピーする。
呼び出し側は、入力バッファ内で63 byte以内に終端0のある文字列を渡す。
R0・R3・R5・R6とzero flagを変更し、R1・R2・R4・R7は保持する。
R5はコピー先のポインタで、復帰時はR5・R6とも終端0を指す。
コピーするbyteが0でも、STBで書いてから終了を判定する。
CALLI / RETは戻り先だけをスタックへ置き、サブルーチンの入れ子は使わない。
