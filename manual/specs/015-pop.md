## Day 15: POP

```text
名前: POP
分類: stack instruction
目的: スタックから32bit値を取り出してレジスタへ入れる
命令長: 4 byte
bit配置:
  bits 31..28: type = 7
  bits 27..24: op = 1
  bits 23..20: rd = destination register
  bits 19..0 : unused = 0
読むレジスタ: SP
書くレジスタ: rd, SP
読むメモリ: memory[SP] から memory[SP + 3] までの4 byte
書くメモリ: なし
PCの変化: fetch時に +4
条件フラグの変化: なし
エラー時: register number が範囲外、または SP から4 byte読めないなら停止
手作りテスト: POP R1 -> 0x71100000
成功条件: SP = 0x000FFFFC かつ memory[SP..SP+3] = 12 34 56 78 のとき、実行後 R1 = 0x12345678 かつ SP = 0x00100000
```

テストプログラム:

```text
POP R1
HALT
```

メモリ配置:

```text
0x00000000: 71 10 00 00    POP R1
0x00000004: 01 00 00 00    HALT

0x000FFFFC: 12 34 56 78    stack data
```

このVMのスタックは下方向に伸びます。

```text
POP前: SP = 0x000FFFFC
POP後: SP = 0x00100000
```

`POP` は、まず `SP` が指している場所から32bit値を読み、そのあと `SP` を4増やします。

```text
regs[rd] = memory[sp..sp+3];
sp += 4;
```

読み取り順は `LDDI` と同じく big-endian です。

```text
12 34 56 78
=> 0x12345678
```

Cで書くなら:

```c
regs[rd] =
    ((uint32_t)memory[sp] << 24) |
    ((uint32_t)memory[sp + 1] << 16) |
    ((uint32_t)memory[sp + 2] << 8) |
    ((uint32_t)memory[sp + 3]);
sp += 4;
```

```text
0x 7 1 1 00000
   | | |   |
   | | |   +-- unused = 0
   | | +------ rd = 1
   | +-------- op = 1
   +---------- type = 7
```
