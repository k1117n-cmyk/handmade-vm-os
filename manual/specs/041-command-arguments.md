# Day 41: コマンド名と本文を分ける

## 目的と成功条件

`programs/command-arguments.asm`を既存small-asmで変換し、VM上で`echo hello`に対して`hello`とLFを表示してCommand>へ戻る。Day 40のサンプルは比較用に残す。VM本体・命令・syscall・small-asm・既存writer・既存テストの期待値は変更しない。

## 承認済みの入力仕様

- コマンドの先頭にある半角空白（0x20）を読み飛ばす。空行・半角空白だけの行はUnknown command。
- コマンド名は最初の半角空白またはNULまで。大小文字を区別し、help / quit / echoの完全一致で判定する。
- コマンド名の後の連続する半角空白を区切りとして読み飛ばす。以後は行末までを1つの本文とし、途中と末尾の空白を保持する。
- タブは区切りに含めない。引用符・バックスラッシュは通常の文字として扱い、解釈しない。
- `echo hello world`は`hello world`とLFを表示する。
- `echo`単独（区切りなし）は従来どおりText>で次の1行を読み、表示する。先頭空白だけが付いたechoも同じ。
- `echo `のように区切りがあり本文が空なら、LFだけを表示する。次の行はコマンドとして扱う。
- help / quitに空白以外の引数があればUnknown command。末尾に半角空白だけが付く場合は受理する。

### ヘルプ表示（ユーザー承認済み）

Day 40のechoの案内行`echo: read and print a line`を、Day 41では`echo [text]: print text or read a line`へ変更する。ユーザー承認済み。実装のhelp_textとテストのHELP期待値もこの文言とする。行末はLFとし、Commands:、help、quitの案内行は変更しない。`[text]`は本文を省略できることを示す案内表記であり、入力時に角括弧を解釈する構文ではない。

## 行入力とメモリ

Day 36・40のread_lineを継承する。0x500〜0x53Fの64 byteを使い、最大63 byteと終端0を保存する。先頭空白・コマンド名・区切りも63 byteに含む。超過分はLFまで消費する。CRは行中も無視、LFで確定する。途中EOFは既存SYSCALL 2でinput EOFを表示して停止し、未完の行を実行・表示しない。

NULは保存し、分割・比較・表示は最初のNULまで。入力はNUL以後もLFまで消費する。切り詰め後の保存内容で判定する（例: 59個の空白+echoは区切りなし、58個の空白+echo+空白は空本文）。UTF-8もbyte列として保存し、境界で文字が切れる場合がある。

最初の区切りを0へ置き換え、同じバッファ内でコマンド名を0終端にする。本文はコピーしない。命令を0から、文字列を命令直後へ配置する。ファイル末尾（排他的）が0x500以下であることをテストする。固定の命令数・ファイルサイズや旧版との全体一致は要求しない。

## 部品とレジスタ

- read_line: R0〜R2とzero flagを変更。既存の入力処理。
- split_line: 0x500から分割。R6は本文（または終端0）のアドレス、R7は区切りがあれば1、なければ0。R0・R2・R3・R6・R7とzero flagを変更する。
- compare_command: R2に比較語のアドレスを受け、R1を0x500から最初の非空白へ進めて文字列比較する。一致ならR0=1、不一致なら0。R0〜R4とzero flagを変更し、R6・R7を保つ。
- 本文表示: R6からLDBで1 byteずつ読み、SYSCALL 3で表示する。終端0の後にLFを表示する。echo単独の場合は従来どおりSYSCALL 1を使う。
- CALLI / RETは戻り先スタックだけを使い、サブルーチンの入れ子は不要。書き込むメモリは入力バッファと戻り先スタック。

## 検証と対象外

分割部品を一時的なVMプログラムに組み込み、コマンド・本文・区切り有無を固定期待値で照合してから、コマンドループを確認する。新しいVM機能ではないためnotes/vm.cへの統合は不要。

統合後は空白、空本文、echo単独、help / quitの引数拒否、反復、上限、CRLF、EOF、NUL、UTF-8、monitor復帰を出力全体・終了コード・標準エラーで照合する。旧版の配置と入出力テストも維持する。

未決事項: 今回の範囲には無し。引用符の解釈、複数引数、行編集、保存は対象外であり、次回以降に仕様を決める。
