## Day 17: CMP

```text
名前: CMP
分類: arithmetic-register instruction
目的: 2つのレジスタの32bit値を比較し、zero flagを更新する
命令長: 4 byte
bit配置:
  bits 31..28: type = 2
  bits 27..24: op = 4
  bits 23..20: rd = left register
  bits 19..16: rs = right register
  bits 15..0 : unused = 0
読むレジスタ: rd, rs
書くレジスタ: なし
読むメモリ: なし
書くメモリ: なし
PCの変化: fetch時に +4
条件フラグの変化: regs[rd] == regs[rs] なら zero_flag = true、それ以外なら false
エラー時: register number が範囲外なら停止
手作りテスト: CMP R0, R1 -> 0x24010000
成功条件: R0 = 10, R1 = 10 のとき zero_flag = true
```

`CMP` は、次の分岐命令 `JZ` の準備になる命令です。

```text
CMP R0, R1
```

は、`R0` と `R1` の値を比べます。

```text
R0 == R1 なら zero_flag = true
R0 != R1 なら zero_flag = false
```

大事なのは、`CMP` はレジスタの値を変えないことです。

```c
vm->zero_flag = vm->regs[rd] == vm->regs[rs];
```

`ADD` や `SUB` は `rd` の値を書き換えます。

```c
regs[rd] += regs[rs];
regs[rd] -= regs[rs];
```

しかし `CMP` は、比較結果だけを `zero_flag` に残します。

テストプログラム:

```text
MOVI R0, 10
MOVI R1, 10
CMP R0, R1
MOVI R2, 10
MOVI R3, 3
CMP R2, R3
HALT
```

メモリ配置:

```text
0x00000000: 40 00 00 0A    MOVI R0, 10
0x00000004: 40 10 00 0A    MOVI R1, 10
0x00000008: 24 01 00 00    CMP R0, R1
0x0000000C: 40 20 00 0A    MOVI R2, 10
0x00000010: 40 30 00 03    MOVI R3, 3
0x00000014: 24 23 00 00    CMP R2, R3
0x00000018: 01 00 00 00    HALT
```

```text
CMP R0, R1

0x 2 4 0 1 0000
   | | | |   |
   | | | |   +-- unused = 0
   | | | +------ rs = 1
   | | +-------- rd = 0
   | +---------- op = 4
   +------------ type = 2
```
