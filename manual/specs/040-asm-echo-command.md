# Day 40: echoを.asmへ移す

## 目的と成功条件

Day 36のechoを、Day 39までのsmall-asmだけで記述する。`programs/asm-echo-command.asm`から生成したバイナリが既存echoと同じ入出力を示し、54ケースを通過すること。

## 配置の決定

- 命令を0から既存writerと同じ順番に並べ、その直後へ8個の0終端文字列を連続配置する。
- 文字列参照はMOVIのラベル、分岐・呼び出しはラベルで書く。
- 入力バッファは0x500〜0x53Fの64 byte。保存は63 byteまで、最後の1 byteは終端0用。命令・文字列の末尾（排他的）が0x500以下であることを検証する。
- VMはメモリを0で初期化し、ファイルをアドレス0から読む。バッファをファイルに含める必要はない。
- 文字列を旧アドレスに固定する必要はないため、絶対配置指示は追加しない。命令の後ろにしかデータを置かないので.align 4も不要。
- このサンプルの重なりは専用テストで検出する。small-asm自体は0x500を予約領域として認識しない。

## 照合の範囲

既存writerの生成物は比較用に残し、別名のasm-echo-command.binを追加する。命令数・順序・分岐先・呼び出し先・バッファ即値は同一。8個の文字列を参照するMOVIだけアドレスが変わるため、それ以外の命令byteは完全一致を要求する。各文字列は終端0を含め一致させる。空き領域と文字列の絶対位置は変わるため、ファイル全体のcmpは要求しない。

## 動作

help / quit / echoの完全一致判定、unknown後の再入力、echoでText>を表示して次の行を読む動作はDay 36のまま。CRを無視し、LFで確定する。上限を超えてもLFまで消費する。EOF時は未完成の本文を表示せず停止する。入力・本文は同じバッファを再利用する。

## 対象外

VM命令・syscall・small-asm構文の追加、引数分割、行編集は行わない。
EOFや埋め込みNULも既存54ケースの期待値を維持する。
